How to solve Futoshiki

Futoshiki is a Japanese puzzle name that means "inequality". The puzzle is a square grid, like a Sudoku without boxes. You fill it with the numbers 1 to N so that no number repeats in any row or column, and so that every inequality sign between two squares is true. Some squares may already hold a number.

The rules

  • Each row contains each number from 1 to N exactly once.
  • Each column contains each number from 1 to N exactly once.
  • A sign such as < between two squares means the number on the open side is bigger.

Techniques

  1. Extremes. A square that must be smaller than a neighbour cannot be N. A square that must be bigger than a neighbour cannot be 1. A square with a sign "smaller than" on both sides is often 1 or 2.
  2. Chains. If a < b < c in a row, then a is at most N-2, b is between 2 and N-1 and c is at least 3.
  3. Missing digits. In a row with four numbers filled in out of five, the last square has only one possible value.
  4. Pairs. If two squares in a row can only be 1 or 2, those digits cannot go anywhere else in the row.

How many grids exist?

The number of ways to fill an N by N grid so that no number repeats in a row or column grows very fast: 4 by 4 has 576 grids and 5 by 5 has 161,280 (both counted by our program), 6 by 6 has 812,851,200 and 7 by 7 has 61,479,419,904,000 (the known values of this number sequence). The signs and starting numbers in a puzzle are chosen so that only one of those grids fits, and our program checks that for every puzzle.

Practise

Begin with a 4 by 4 easy puzzle and move up. The list of puzzles has four sizes and three levels.
