Daily Kakuro

One puzzle a day, the same for everyone who plays on that date.

How the daily puzzle works

The puzzle is made from today's date on your device, so everyone gets the same one and tomorrow brings another. Progress is saved on your device for the day. Try the daily Futoshiki as well, or a bigger puzzle in the Kakuro section.

A tip for today

Start with the runs of two squares: a total of 3, 4, 16 or 17 has only one pair of digits, so you can pencil those in straight away. Then look at the squares where a row and a column meet, and rule out any digit that would repeat in either run. If a few grey starter digits are shown, begin near them, because they were chosen to unlock the rest. The cheat sheet lists every set of digits for every total.

There is no timer and no penalty for using Check, so use it to learn. If you are completely stuck, Show solution reveals the answer and you can press Start again to try from the beginning.
