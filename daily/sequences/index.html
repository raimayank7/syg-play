Number sequence types

Every number sequence in the daily puzzle follows one of seven kinds of rule. Learn them once and you can solve almost any sequence puzzle. Each page explains the rule, shows worked examples and gives you practice questions with answers.

  • Arithmetic sequences Add the same number each time
  • Geometric sequences Multiply by the same number each time
  • Square number sequences The squares: 1, 4, 9, 16, 25
  • Triangular number sequences Add one more each time: 1, 3, 6, 10, 15
  • Fibonacci-type sequences Add the two terms before
  • Alternating sequences Two steps repeated
  • Cube number sequences The cubes: 1, 8, 27, 64, 125

A method for any sequence

  1. Write down the gaps between neighbouring terms.
  2. If the gaps are equal, it is arithmetic.
  3. If the terms multiply by the same number, it is geometric: divide neighbours to check.
  4. If the gaps change steadily, look at the gaps of the gaps, which points to squares, triangular numbers or cubes.
  5. If each term seems to depend on the two before it, try adding them.
  6. If the gaps alternate, look for two steps repeated.
