Arithmetic sequences: Add the same number each time

In an arithmetic sequence you add (or subtract) the same number every step. The gaps between neighbouring terms are all equal, so you can find the rule by subtracting the first term from the second. These are the easiest sequences and the first ones children meet at school.

How to spot it

Subtract each term from the one after it. If all the answers are the same, you have an arithmetic sequence, and that number is the common difference. The next term is the last term plus the difference. A shortcut for any term is first term + difference × (position − 1).

Step by step

Take the sequence 11, 19, 27, 35, 43. Step 1: write the gaps between neighbours: 8, 8, 8, 8. Step 2: write the gaps of the gaps: 0, 0, 0. Step 3: write the ratios of neighbours: 1.73, 1.42, 1.3, 1.23. Compare the three lines. The line that is steady (all the same) or follows a simple pattern tells you the rule. Here the rule is: add 8 each time, so the next number is 51.

Worked examples

Common mistakes

A common mistake is to check only the first gap. Check all of them: a sequence such as 2, 5, 9, 14 has gaps 3, 4, 5, which are not equal, so it is not arithmetic. Another is to forget that the difference can be negative: 40, 35, 30 subtracts 5 each time.

Where you meet this kind of sequence

Arithmetic sequences appear everywhere: a bus that comes every 12 minutes, a salary that rises by a fixed amount each year, or the marks on a ruler. They are the first sequences taught in school, and the base of simple interest sums.
