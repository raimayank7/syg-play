How a fair shuffle works

A deck of 52 cards can be arranged in 52! ways, a number that begins 806581 and has 68 digits. Any fair shuffle must give each of those orders the same chance. This page explains how the tools here do it and what to avoid if you write your own.

Fisher–Yates

Start with the last card. Swap it with a randomly chosen card from the whole deck including itself. Move to the second-last card and swap it with a random card from the cards before it and itself. Carry on to the front. Every order comes out with the same chance, because each step makes one fair choice among all that remain.

A common mistake

A tempting shortcut is to swap each card with any card in the deck. It looks fine but favours some orders. For a deck of just three cards it makes 27 equally likely sequences of swaps, which cannot divide evenly among the 6 possible orders, so some orders come out more often than others. Sorting with a random comparison has similar problems.

Where the randomness comes from

Each choice uses a number from the browser's secure random generator, scaled to the range needed without bias: values that would cause some results to be slightly more likely are thrown away and drawn again. The card draw tool uses exactly this.
