How often do streaks happen in fair coin flips?

If a coin lands heads five times in a row, most people feel the coin is "due" tails or that something is wrong. This page shows what really happens: in a fair coin, long runs are normal. The chances below are exact, worked out by following every possible sequence step by step.

For example, in 100 flips you will see a run of at least 6 identical results 80.7% of the time and a run of at least 7 about 54.2% of the time. In 20 flips a run of 4 is 76.8% likely.

Why people get this wrong

People imagine random sequences as alternating more than they do. When asked to write down a made-up string of flips, almost everyone avoids long runs, and a string with a run of six looks fake. Real fair flips contain such runs often. Teachers use this to show how a made-up sequence can be told from a real one: look for the longest run.

The coin has no memory

After any run, the next flip is still one in two. A run does not change the coin, so there is no "due". The coin flip tool shows your current run so you can watch long streaks appear.
