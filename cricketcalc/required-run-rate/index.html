Required run rate calculator

In a chase, the required run rate is the number of runs the batting side must score every over from now on to reach the target. Compare it with the current run rate to see whether the team is ahead or behind the game.

How to use it

  1. Type the target, meaning the number of runs needed to win (first-innings total plus one).
  2. Type the runs scored so far and the overs bowled so far (18.4 means 18 overs and 4 balls).
  3. Type the total overs in the innings and press the button.

A worked example

The target is 165 in 20 overs. After 12.3 overs the score is 88. Balls left = 120 − 75 = 45, which is 7.5 overs. Runs needed = 165 − 88 = 77. Required rate = 77 ÷ 7.5 = 10.27. The current run rate is 88 ÷ 12.5 = 7.04, so the batting side is well behind the pace and must score about 3.2 runs an over more than so far.

Mistakes to avoid

  • Using the first-innings total as the target. The target is one more than the total, because a tie is not a win in a normal chase.
  • Taking overs left as 20 minus 10.3. That is 9.7 on a calculator but really 9 overs and 3 balls, which is 9.5 overs. The tool counts balls.

Questions people ask

What is the difference between target and runs required?

The target is the total needed to win. Runs required is the target minus what has already been scored.

Can the required rate go down while the team scores slowly?

Yes, if the team scores more than the required rate in an over it drops; it rises when the team scores less.

Does this include rain-reduced matches?

Type the revised target and the revised overs. The sum is the same.
