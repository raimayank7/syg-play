Overs to balls converter

Cricket writes overs in a way that trips up every spreadsheet: 12.4 means twelve overs and four balls, not twelve point four. Before you can work out any rate you must turn overs into balls or into a true decimal. This page does that in one step.

How to use it

  1. Type overs like 12.4 to get balls and the decimal value.
  2. Or type a number of balls to get overs and balls.
  3. Use the decimal value when you work out a rate by hand.

A worked example

12.4 overs = 12 × 6 + 4 = 76 balls = 12.667 overs. Adding 3.3 overs (21 balls) gives 97 balls = 16 overs and 1 ball, written 16.1, not 15.7.

Mistakes to avoid

  • Adding overs as decimals. 12.4 + 3.3 is not 15.7; it is 12 overs 4 balls plus 3 overs 3 balls, which is 16 overs 1 ball (16.1).
  • Typing 12.7. An over has six balls, so the digit after the dot can only be 0 to 5.

Questions people ask

Why does cricket not use decimals for overs?

Because an over is six balls, not ten parts. The dot separates complete overs from balls bowled in the current over.

How many balls are in an ODI innings?

Fifty overs is 300 balls. A 20-over innings is 120 balls.
