Run rate and projected score

The current run rate is runs scored divided by overs bowled. If the team keeps scoring at that pace, the projected score is the run rate times the total overs. This calculator also shows what the score would be if the rest of the innings was played at 6, 7, 8, 9, 10 or 12 runs an over.

How to use it

  1. Type the runs scored and the overs bowled so far.
  2. Type the total overs in the innings.
  3. Read the current run rate, the projected score and the table of scores at different speeds.

A worked example

Score 54 after 6 overs in a 20-over innings. Run rate = 54 ÷ 6 = 9.00. Projected score = 9.00 × 20 = 180. If the next 14 overs go at 8 an over the team finishes on 54 + 112 = 166; at 10 an over, on 194.

Mistakes to avoid

  • Treating the projection as a forecast. Late overs are usually faster than early ones, so a straight-line projection often underestimates the end score of a set batting side and overestimates one that has just lost wickets.
  • Using overs like 6.2 as a decimal. It is 6 overs and 2 balls, 6.333.

Questions people ask

Why is projected score not the same as the final score?

It assumes the current pace never changes, which seldom happens. It is a quick guide, not a prediction.

How do I read the table?

Each row shows the final score if the remaining balls are scored at that many runs an over.

Does it allow for wickets?

No. It looks only at runs and overs.
