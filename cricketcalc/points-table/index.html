Cricket points table maker

Whether it is a school cup, a society league or an office tournament, someone has to keep the table. This tool takes each team's wins, losses, ties and no-results, adds the points, works out net run rate from the run and over totals, and sorts the teams the way most leagues do.

How to use it

  1. Type each team's name and its wins, losses, ties and no-results. Leave a box empty if it is zero.
  2. To get net run rate in the table, also type the totals: runs scored, overs faced, runs conceded and overs bowled across all of that team's matches. For an all-out innings add the full quota of overs.
  3. Check the points for a win and for a tie or no-result. Two points for a win and one for a tie or no-result is the system in the ICC ODI and T20I playing conditions (clause 16.10.1, October 2026) and in the IPL playing conditions 2026, and is common in club leagues; some leagues give three or four for a win, so change it to match your rules.
  4. Press "Make the table". Teams are ordered by points, then number of wins, then net run rate: the order in the ICC and IPL playing conditions. Some leagues also look at the result between the tied teams (head to head) before net run rate; this tool does not.
  5. Use the WhatsApp or Copy button to send the table to the group.

A worked example

Three teams finish a round on 4 points each (two wins from three, or one win and two ties, in a league with 2 points for a win and 1 for a tie). The table puts the team with the best net run rate first. If you need that rate, use the net run rate calculator for each team and copy the totals into this table.

Mistakes to avoid

  • Entering overs as decimals. Eighteen overs and four balls is 18.4, not 18.67.
  • Leaving the net run rate totals empty. The table still works, but teams on equal points are then ordered by wins only.
  • Using a different tie-break from your league. Some tournaments check the result between the two teams (head to head) before net run rate; if yours does, adjust the order by hand.

Questions people ask

How many teams can I enter?

Six lines are shown, which suits most small leagues. For a bigger league make one table per group and copy each.

Why are two teams with the same points in a different order?

Net run rate decides it. The team with the higher rate goes first. If that is also equal, the team with more wins goes first.

Can I save the table?

Copy it with the button and paste it into a message or a note. Nothing is stored on our side.
