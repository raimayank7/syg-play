Net run rate calculator

Net run rate, written NRR, is the tie-breaker of nearly every cricket league: when two teams finish on the same points, the one that scored its runs faster and conceded them slower goes higher. This calculator takes every match a team has played and gives the NRR for the whole tournament so far.

How to use it

  1. Type the number of overs in a full innings: 20 for a T20 league, 50 for a one-day league, or whatever your local tournament plays.
  2. For each match type the runs your team scored and the overs it faced, then the runs it conceded and the overs it bowled. Overs are written the cricket way: 18.4 means 18 overs and 4 balls.
  3. If a side was bowled out, tick the "all out" box for that side. The calculator then uses the full quota of overs for that innings, which is the standard rule, instead of the overs actually batted.
  4. Press the button. The answer shows the run rate for, the run rate against and the difference, so you can see where the number comes from.
  5. Use "Add a match" for more matches. Matches that ended in a no-result are normally left out of net run rate; leave those lines empty.

A worked example

A team plays three 20-over matches. In match 1 it scores 176 in 20 overs and concedes 168 in 20. In match 2 it chases 141 and scores 142 in 17.2 overs, with the opponents all out for 141. In match 3 it is bowled out for 95, and the opponents knock off the 96 they need in 14.3 overs.

Runs scored: 413. Overs faced: 20 + 17.2 + 20 (all out counts as the full 20) = 57.2 overs, which is 344 balls = 57.333 overs. Rate for: 413 ÷ 57.333 = 7.20.

Runs conceded: 405. Overs bowled: 20 + 20 (opponents all out in match 2) + 14.3 = 54.3 overs, which is 327 balls = 54.500 overs. Rate against: 405 ÷ 54.500 = 7.43.

Net run rate = 7.20 − 7.43 = -0.228. Try the same numbers in the calculator above.

Mistakes to avoid

  • Typing 18.4 overs as 18.4 is right, but then working it by hand as 18.4 overs instead of 18.667 overs gives a wrong rate. The calculator converts balls for you.
  • Forgetting the all-out rule. A team bowled out for 120 in 14 overs of a 20-over match is treated as having faced 20 overs, so its rate is 6.00, not 8.57.
  • Mixing quotas. If some matches were shortened by rain, use the revised overs for that match only if your tournament rules say so; this tool uses one quota for all lines.

Questions people ask

Is net run rate the same as run rate?

No. Run rate is runs divided by overs for one innings. Net run rate is the run rate your team scored at, over all its matches, minus the run rate it conceded at.

Does a big win help more than a small one?

Yes, because a bigger margin raises your rate for or lowers your rate against. Winning quickly while chasing also helps, since you faced fewer overs for your runs.

Why does the all-out rule exist?

Without it, a team could make its run rate look high by being bowled out cheaply and quickly. Counting the full quota treats an all-out innings as the whole allowance of overs spent.

Which tournament rules does this follow?

The rule in the ICC men’s ODI and T20I playing conditions effective October 2026 (clause 16.10.2, read on icc-cricket.com on 13 November 2026): runs per over scored minus runs per over conceded over the whole competition, with an all-out innings counted at the full quota of overs. No-result matches are left out. Local tournaments may add rules for shortened matches, so check yours.
