Free Online Score Sheet for Any Game

A simple score sheet for any game with rounds: cards, board games, quizzes. Add players, add a round, type the scores and the totals and the leader update by themselves.

How to use it

  1. Start with the names: tap a name and type over it. Add up to eight players.
  2. Press Add round for each round and type each player's score in the box.
  3. Totals appear in the bottom row and the page says who leads.
  4. Press Print sheet for a paper copy, or New game to clear it.

Saved on your device

Everything is saved in your own browser as you type, so you can close the page between rounds and come back. Nothing is sent to us. If you use a different phone or clear the site data, the sheet starts empty again.
