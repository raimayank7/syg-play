Tambola

Tambola ticket maker

Print fresh tambola tickets in one click. Every strip has six tickets that together use all numbers from 1 to 90 once. Add your party name, press Make tickets, then Print.

How to use the tickets

  1. Choose how many strips. One strip is six tickets, so four strips make 24 tickets.
  2. Type a title if you want one, for example the name of the party.
  3. Press Print. Choose A4 paper and cut each ticket along its border.
  4. Give each player one or two tickets. See how many tickets you need.

What makes a ticket valid

A tambola ticket has 3 rows and 9 columns. Each row holds exactly five numbers and four blanks, and each column holds at least one number. The first column takes numbers 1 to 9, the second 10 to 19, and so on until the ninth column, which takes 80 to 90. Numbers rise from top to bottom in a column. The maker checks all of this on every strip before showing it.

Next steps

Call the numbers with the number caller, read the rules and decide on prizes.

Printing tips

  • Choose A4 and "fit to page" for a strip of six tickets on one sheet.
  • Print in black and white to save ink; the blank squares are shaded so players can see them.
  • For a big group print a few spare strips, as tickets get lost or wet.
  • If your printer cuts off the edges, use landscape mode or print fewer strips on a page.

If you prefer PDF

In the print window choose Save as PDF as the printer. You can then send the PDF to a print shop or share it in a group.
